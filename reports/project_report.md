# Project Report

## Overview
This project analyzes garment worker productivity and develops prediction models to assess whether productivity targets are likely to be achieved.

## Objectives
- Evaluate productivity performance across departments and teams
- Identify operational drivers affecting productivity
- Compare predictive models for forecasting productivity
- Deliver actionable insights through a Power BI dashboard

## Methodology
1. Data collection from SQL Server
2. Data cleaning and preprocessing
3. Exploratory data analysis
4. Regression modeling
5. Classification modeling
6. Feature importance analysis
7. Dashboarding and reporting

## Findings
- Idle time and overtime are typically strong productivity drivers
- Department-level and team-level differences are significant
- Predictive modeling can help anticipate underperformance

## Recommendations
- Monitor idle time and overtime closely
- Improve workforce balancing by department
- Use model outputs for operational decision support
